# 秋招行测题库 · 银行 EPI（网站 + 单文件）

**线上地址：<https://timothy-yqw19.github.io/qiuzhao-epi-bank/>** —— 已部署在 GitHub Pages，带 HTTPS，手机可「添加到主屏幕」当 App 用。

一个可以**当网站用、也可以离线双击用**的行测刷题应用。当前题库 **697 题** = 手写原题 134 + 出题器生成 563。

- **网站版（GitHub Pages 部署用）**：**仓库根目录就是网站**，推到 GitHub 后开 Pages 即可（含 PWA：可离线、可「添加到主屏幕」）。本机已起服务：<http://127.0.0.1:8788/>
- **单文件版**：`index.html`，双击即可用，不需要联网、不需要安装。

## 怎么用

1. 打开网站地址（或双击 `index.html`）。
2. 第一次进来先去「**题库**」筛一组，或到「**刷题计划**」点某天的「开始」。
3. 做题时在题目下方的「**我的思路笔记**」里随手写：卡在哪一步、用了什么技巧、下次怎么更快。**边做边写，自动保存。**
4. 答错自动进「**错题本**」，「**数据**」页能看到各模块正确率，据此决定补哪一块。
5. 题不够就无限刷：练习页/计划页的「自由刷题」按钮可从生成题池随机抽 20/50/100 题，或按题型专练。

> 换电脑、清理浏览器数据前，去「数据」页点「导出全部数据」备份。所有记录只存在本机浏览器里，不会上传。
>
> 注意：`file://` 打开和 `http://127.0.0.1:8788/` 打开是**两个独立的存储域**，进度不互通。建议固定用一种方式。

## 命令怎么复制（常见坑）

下面所有命令块都写的是**本机真实绝对路径**，可以直接整段复制。但仍然注意三点：

- **`$PY`、`$NODE`、`/path/to/...` 都是占位符**，直接粘会报 `command not found` 或 `no such file or directory`。用上面写好的完整路径。
- **`#` 开头的行是注释**，粘进终端会被当成命令（`zsh: command not found: #`）。要么别粘，要么先去掉 `#`。
- **别在家目录 `~` 里起服务**。`python3 -m http.server --directory .` 的 `.` 是「当前目录」，在 `~` 里执行就会把你整个家目录挂出去，页面只会显示目录列表、`sw.js` 标 404。用 `bash serve.sh`（它会自己切到项目目录），或者先 `cd` 到项目目录再起服务。
- 端口被占用时（`Address already in use`）：先在前一个终端按 `Ctrl-C`，或 `bash serve.sh 8789` 换端口。

## 已知边界（重要）

- **生成题是「考点对、形式模板化」的练习题，不是真题**。它的价值在于量和即时反馈（答案经程序反算，不会错），但措辞比真题单调，且只覆盖 4 个可机器验算的题型；言语理解、图形推理、定义判断、类比推理、常识这些需要语义判断的题型**没有生成**，仍只有手写的 92 道。
- **常识判断 12 题（123–134）原文只有技巧与答案，没有逐步解析**，应用里标「无解析」。
- **原题来源标注基本缺失**：源文档承诺每题标 `【真题】`/`【仿真】`，实际正文只有第 68、78、92 三题标了「（真题）」。应用未编造来源。
- **原题答案分布偏斜**：A 32 / B 54 / C 39 / D 只有 9，且 33–40 连排 8 个 A。生成题的答案分布是平的（约 1:1:1:1），可以对照检验自己有没有「蒙选项位置」的坏习惯。
- **原题答案只做了抽样复核**（第 1、3、41、42、43、88、92、100、111、112、114、115、126、134 题逐题验算均成立），**没有做 134 题全量重解**。存疑就用「标记存疑」，会汇总在「数据」页。
- **视觉已验证**：用 Chrome 无头模式（`--no-sandbox`）截了题库页、练习页（原题/生成题）、速查卡、计划页四类页面，渲染正常。截图过程中发现并修掉了两个真实 bug：题干/技巧里的 `**` 被原样显示、附录表格里 `a < b` 的 `<` 被当成 HTML 标签把表格撕开——现已统一为「先转义再转 markdown 加粗」，并加了回归断言。
- 附注：Chrome 全页截图里页头会在底部重复出现一次，那是 sticky 定位元素在拼接截图时的假象（`index.html` 里只有一个 `<header>`），实际浏览不会重复。

## 网站部署

**仓库根目录即静态站点**，任意静态托管都能用：

```bash
cd "/Users/wangsheng/Documents/deepseek-harness/default-workspace/秋招行测题库"
```

- **GitHub Pages**：推到 GitHub 后，仓库 **Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/(root)`**，保存后约 1 分钟生效，网址形如 `https://<用户名>.github.io/<仓库名>/`。`.nojekyll` 已包含，不需要额外配置。
- **Vercel / Netlify**：导入这个仓库即可（无需构建命令、无需输出目录），或把根目录拖进面板。
- PWA 的 Service Worker 需要 **https 或 localhost** 才生效；用 `file://` 打开时会自动跳过注册。
- 离线策略：**页面网络优先**（更新立刻生效，断网回退缓存），图标等静态资源缓存优先；缓存版本号 = `index.html` 内容哈希，改内容即自动失效旧缓存。

下面用的是本机 bundled 运行时的**真实绝对路径**（可直接复制）：

> `build_site.py` 需要 Pillow（用来画 PWA 图标），所以用 bundled python；其余脚本用系统 `python3` 也行。

- `build_bank.py`、`gen_quant.py` 都只读源文件，不改动原题库。
- 想出更多生成题：改 `gen_quant.py` 的命令行参数（`--n-digital` / `--n-math` / `--n-material` / `--n-logic` / `--seed`），换个 seed 就是一套新题。
- `gen_quant.py` 出厂自检不通过会返回非 0 并列出问题。
- 想改界面：编辑 `app_template.html` 再跑 `build_html.py` + `build_site.py`。
